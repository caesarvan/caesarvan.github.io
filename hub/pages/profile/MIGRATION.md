All six original HTML pages and the complete `assets/` directory are included.
The original bilingual copy, five-stage study/work timeline, projects, awards,
about page, GitHub contact links, and image/font source notes are retained.
The source repository and local source copy are preserved.

In the Life Hub frame (`?embed=1`, same origin), the shared application owns
the site navigation and theme. This module displays only its six page tabs
and language control. `embed` and `lang` are retained while navigating between
profile pages. Standalone URLs retain the original profile header and footer.
The hub's `embed.js` handles height, theme, and navigation to other modules.

The original animated power chart is an illustration. Its original `LIVE`
badge is relabeled as a demo, with a bilingual note clarifying that the
displayed values and waveforms are not device, work, or live telemetry data.

`BRAND_ASSETS.md` records the upstream image and institutional-mark sources;
the included font license is `assets/fonts/LICENSE.txt`. Those source records
are retained as provenance, not as a new determination of usage rights.
Two upstream remote illustration URLs remain remote references and can fail
independently; the product references include a visible fallback and source
links. No additional private documents, credentials, or account details are
introduced by this migration.
