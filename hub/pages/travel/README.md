# 旅行手记：本机数据模式

公开页面只包含旅行界面、图表、筛选及导入功能，不包含个人旅行记录。

在页面顶部选择旅行 JSON 文件后，文件在当前页面内存中解析和展示，不上传、不跨设备同步。刷新页面或选择“清除本机数据”会移除当前导入的记录。

支持现有旅行看板的完整 JSON 快照：顶层 `queries.trips.rows` 为旅程，`queries.segments.rows` 为交通／住宿明细；可包含 `filters`、`coverage`、`generatedAt`、`timezone` 及来源说明。每条记录使用唯一 `id`，明细通过 `tripId` 关联旅程。文件最大 10 MB。页面会拒绝缺失的查询、无效日期、重复编号及危险来源链接。

页面链接只分享界面，不能分享本机已导入的数据。需要在另一台设备查看时，应由本人安全转移数据文件并重新导入。
