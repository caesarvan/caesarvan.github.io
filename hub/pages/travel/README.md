# 旅行手记：自动读取已发布数据

本页面自动读取 `../../data/travel.json`，打开后直接显示已发布的行程快照，无需本机导入。顶部标明快照时间，并提供读取失败提示和重新读取按钮。

数据保留 `queries.trips.rows`、`queries.segments.rows` 及可选 `queries.locations.rows`；明细通过 `tripId` 关联旅程，坐标按 WGS84 表示。历史预订记录不等同实际成行；内容以快照及对应资料的核查边界为准。

页面、数据和 Git 提交历史均位于公开仓库；链接可以分享同一已发布快照。此部署不会自动同步邮件、日历或后台账户。原始凭证和附件不随本页面发布。
