# 网页接入与发布标准 v3

更新日期：2026-10-23；目标仓库 caesarvan/caesarvan.github.io。

- 统一入口：https://caesarvan.github.io/ 自动进入 https://caesarvan.github.io/hub/ 。2026-10-23 用户明确授权删除旧 Hexo，根站改为 Life OS 入口；原博客退出发布目录，保留 Git 历史与本地恢复归档。已有其他子站及本地原件保留。
- 公共登记表为 hub/modules.json：稳定唯一 id、标题、说明、图标、颜色、group、type、href、mode、order、enabled。登记表同步侧栏、搜索与目录。独立页面 type=page，已有独立站点 type=link。
- 页面放 hub/pages/<id>/index.html，资源相对页面自身；支持不同前端技术栈，最终输出静态文件。Hash 路由支持刷新与分享。
- 用户最新明确要求取消本机导入，把本次已集成看板所需的真实业务数据随网页发布到此公开仓库。该新授权替代此前仅发布框架的选择。公开仓库、网页和提交历史均可能被任何人读取；已授权数据位于 hub/data/，页面自动读取，不要求手动选择本机文件。
- 财务、投资、旅行使用各自已授权的 JSON 快照；保留业务结构与数据时间，首次访问自动载入。提供加载、错误与重试状态，不能把读取失败当作无数据。
- iCloud、OneDrive、邮件及收藏发布已授权的索引、标题与链接；提取静态数据，不执行原索引脚本。附件、证件原件及其他文件不因发布索引而自动全部上传，本地文件条目明确附件未发布；邮件网站仍可能要求原账户登录。
- 密码、验证码、访问令牌、密钥等凭证不进入仓库、日志或发布产物；不上传工作副本、原始附件、source map 或无关个人材料。发布前检查凭证，保留本机原件和核查证据。
- 发布目录记录快照时间、记录数与可用状态；云占位文件无法读取时标记未同步，不生成假记录。网页显示的是已发布快照，不因此自动获得持续同步或后台服务。
- 数据与前端分开更新：业务源会话维护已授权数据文件，框架变更更新页面，两者均通过既有仓库发布。新增资料仍依用户对对应任务的实际授权处理。
- 新增模块校验页面及数据格式，检查自动载入、失败重试和空状态，再提交。发布时验证 HTTP、模块入口、数据文件和原首页，保存提交、CI 与验收证据。
- 同源模块必须是自有受信代码；iframe 提供文档隔离，不作为安全边界。外部站点以链接打开。
- main 分支的自动校验与 Pages 发布并行，现有 CI 不是严格发布前门禁；迁移到 validate → assemble → deploy 时必须组装 Life OS 根入口与全部保留子站。
- 不再从 Hexo 全量生成根站。hub/ 是正式统一工作空间；life-hub-demo/ 仅保留为历史概念演示，不混入真实业务导航。
